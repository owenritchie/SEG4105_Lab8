# HiveCheck
 
## Run it

With Docker:

```bash
docker run --rm -p 8080:5000 owenritchie/hivecheck:latest
```

Or with Python:

```bash
pip install -r requirements.txt
python app.py
```

Then open http://localhost:8080 (Docker) or http://localhost:5000 (Python).
